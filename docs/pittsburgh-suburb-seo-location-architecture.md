# Pittsburgh Suburb SEO Location Architecture

## Purpose

This document organizes Pittsburgh-area suburbs into a local SEO structure for a website. Instead of creating a separate page for every suburb, the recommended approach is:

**15 main suburb landing pages** + **supporting sub-location lists under each page**.

This helps the website target high-value Pittsburgh suburbs while avoiding thin, repetitive location pages.

# Best SEO Implementation

For each of the 15 main suburb pages, use this structure:

## Page Title Example

`[Service] in Mt. Lebanon, PA | Company Name`

## H1 Example

`Professional [Service] in Mt. Lebanon, PA`

## Recommended Page Sections

1. Local intro paragraph for that suburb
2. Services offered in that suburb
3. Why customers in that area choose the business
4. Nearby communities served
5. Local FAQ section
6. CTA button: `Request a Quote in [Suburb]`
7. Internal links to nearby suburb pages
8. Google Business Profile and service-area consistency

---

# Important SEO Notes

Do **not** use the exact same copy on all 15 pages.

Keep the structure consistent, but change the following for each suburb page:

- Opening paragraph
- Nearby location mentions
- Local service-area language
- FAQ questions and answers
- CTA wording
- Internal links to nearby suburb pages
- Any neighborhood-specific references

The goal is to create useful, localized pages that feel written for each Pittsburgh suburb, not copied and pasted across the website.

---

# Suggested Internal Linking Strategy

Each suburb page should link to:

- The main service page
- The contact or quote request page
- 2 to 4 nearby suburb pages
- A service-area overview page
- Relevant blog posts or educational content

## Example Internal Link Section

### Nearby Areas We Serve

We also serve customers in nearby communities including Dormont, Green Tree, Scott Township, Castle Shannon, Brentwood, and Whitehall.

# Suggested URL Structure

Use clean, simple, location-based URLs.

## Recommended Format

`/locations/[suburb-pa]/`

## Examples

- `/locations/mt-lebanon-pa/`
- `/locations/bethel-park-pa/`
- `/locations/upper-st-clair-pa/`
- `/locations/monroeville-pa/`
- `/locations/penn-hills-pa/`

This keeps the website organized and makes it easier to expand into additional locations later.

# Final Recommendation

Start with the 15 main suburb pages first. After those pages are indexed and performing, expand gradually based on:

- Google Search Console query data
- Calls or leads by location
- Competitor rankings
- High-value suburbs
- Search demand
- Service-area priorities

This creates a strong foundation for ranking across the Pittsburgh metro area without overloading the website with weak or duplicate pages.
